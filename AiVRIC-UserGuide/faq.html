FAQ

FAQ & support

Answers to the most common questions. Still need help? Reach out and we'll respond quickly.

General

Where is data processed?

Data stays in your cloud unless you enable optional evidence capture. Control plane metadata is segmented per tenant.

Does AiVRIC support multi-tenant orgs?

Yes. Use workspaces to isolate environments, teams, or geographies. RBAC scopes access accordingly.

Security

Can we self-host?

Talk with us for private cloud deployments. Most customers use the managed service with private connectivity.

How are secrets protected?

Stored via Vault with envelope encryption; no plaintext retrieval after creation; enforced rotation.

Do you provide compliance reports?

Yes. SOC 2, penetration testing summaries, and security architecture docs are in the Trust Center.

Operations

How do updates roll out?

Changes are staged and validated; customer-facing updates are announced in release notes and status communications.

Can we automate remediation?

Yes. Use runbooks attached to controls; actions can auto-open tickets, run playbooks, or call webhooks.

Is there API access?

Export findings, configure guardrails, and manage workspaces via API. Tokens are scoped and expire.
