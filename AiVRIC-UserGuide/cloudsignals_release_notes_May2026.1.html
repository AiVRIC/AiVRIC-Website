What's new in CloudSignals+

This release strengthens enterprise-readiness across TrustSignals, RiskOps, Request Hub, Microsoft 365, Managed Entities, Third-Party Risk, and Vision AI — with a focus on reliability, richer workflows, and a cleaner experience throughout.

May 2026 7 modules updated AiVRIC Technologies
Vision AI
AI-assisted analysis & knowledge layer
Improved
Enterprise workspace UI across all four Vision screens
Light and dark mode now render with separate, purpose-built styling — eliminating the visual compromises of a single shared stylesheet.
New
Expanded CloudSignals platform knowledge
Vision Chat now understands your full CloudSignals environment — assets, findings, scans, compliance, RiskOps, Request Hub, TrustSignals, managed entities, integrations, M365, and commercial context — with permission-scoped access and redaction built in.
New
Light/dark image asset variants
The AI CISO hero, Model Insights orb, and Prompt Vault orb now use mode-specific visual assets for a polished appearance in both themes.
Fixed
Reliable Vision hero image loading & prompt pill overflow
The upper-right Vision Chat hero image loads consistently, and long prompt labels no longer bleed outside pill borders.
TrustSignals
Customer-facing trust portals & artifact workflows
New
Richer customer-facing trust portals
Portals now support custom branding, Managed Entity context, badges and certificates, and structured access request handling end-to-end.
New
Structured artifact request capture
Portal visitors can now formally request SOC 2 reports, bridge letters, certifications, questionnaires, or custom deliverables directly through the portal.
New
Per-Managed Entity TrustSignals profiles
Maintain separate TrustSignals portal content for each Managed Entity — useful for multi-entity or subsidiary-level trust operations.
Fixed
TrustSignals loading & stability
Resolved app-wide slowdowns, branding tab errors, missing Managed Entity options, and backend warning noise.
RiskOps & Request Hub
Risk intake, engagement, and work queue
New
Request engagement workflows
Full request intake and lifecycle support for vendor assessments, questionnaires, risk assessments, evidence requests, approvals, and deliverable tracking.
New
External Request Hub portal
External users and customers can now access request workflows through dedicated portal routes, including invitation handling, catalog browsing, and request submission.
New
My Work queue
Users now have a dedicated view for assigned RiskOps work and pending action items, keeping cross-functional work visible in one place.
Fixed
Request Hub page load & catalog reliability
Page load failures and catalog action fragility resolved; all actions now route through the GRC API layer consistently.
Microsoft 365 & Distribution
Enterprise publishing destinations
New
Microsoft 365 destination management
Configure M365 as an enterprise publishing destination for intelligence reports and operational outputs, with tenant-scoped settings and validation feedback.
Improved
Publishing UX improvements
The distribution backend and publish modal are more stable, with clearer status feedback and better error handling across related modules.
Managed Entities, GRC & Third-Party Risk
Entity management, risk register, and vendor risk
Improved
Managed Entity pages and edit forms
Entity lists and edit screens are more reliable, with hardened backend views, GRC register actions, and the Managed Entity wizard flow.
Improved
Third-Party Risk workflow modernization
Third-party records now carry richer operational context, including data access information and improved register and detail page experiences.
Improved
Risk Register, Business Processes & Quantification stability
Shared reference data handling was consolidated across affected RiskOps pages, reducing load failures and improving API response consistency.
Navigation & Platform Reliability
Sidebar, routing, and deployment improvements
Improved
RiskOps sidebar organization
Related RiskOps workflows are now grouped in the sidebar so they're faster to find, with updated menu entries and navigation tests.
Improved
TrustSignals moved under Compliance
TrustSignals is now where users expect it — inside Compliance and assurance workflows — reducing navigation duplication.
Fixed
Deployment & GitOps pipeline reliability
ArgoCD/GitOps behavior, image verification, and deployment guardrails have been tightened for more consistent dev rollout cycles.
