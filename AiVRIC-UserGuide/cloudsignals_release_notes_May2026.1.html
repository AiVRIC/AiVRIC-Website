CloudSignals+ RiskOps™ Release Notes

What's new in CloudSignals+

The May 2026.1 release strengthens enterprise readiness across seven modules — with a focus on reliability, richer workflows, and a cleaner experience throughout the platform.

v May 2026.1
May 2026.1 — Production Release
Enterprise readiness across Vision AI, TrustSignals, RiskOps & Request Hub, Microsoft 365, Managed Entities, Third-Party Risk, and Navigation. All updates are backward-compatible and deployed automatically.
All Systems Operational
Release: May 2026
7 modules updated
18 improvements
4 bug fixes
3 new features
No action required. This release contains no breaking changes, schema migrations, or configuration changes. All updates are applied automatically to your CloudSignals+ environment.

Release highlights

The three most impactful changes in this release.

Redesigned

Vision AI Enterprise Workspace

Full workspace overhaul with purpose-built light and dark mode styling, mode-specific image variants, and expanded platform knowledge for Vision Chat.

New

TrustSignals Branded Portals

Custom branding, Managed Entity context, badges, and structured artifact request capture (SOC 2, certs, questionnaires) per portal profile.

New

RiskOps Request Workflows

End-to-end vendor assessment and approval workflows with external portal access, a dedicated "My Work" queue, and improved catalog reliability.

Module updates

Click any module to expand the full list of changes.

Vision AI AI Core
Workspace UI · Platform Knowledge · Image Assets
4 changes
Redesigned
Enterprise workspace UI across all four Vision screens
Light and dark mode now render with separate, purpose-built stylesheets — eliminating the visual compromises of a single shared theme and ensuring consistent contrast and spacing in both modes.
New
Expanded CloudSignals platform knowledge in Vision Chat
Vision Chat now understands your full CloudSignals+ environment — assets, findings, scans, compliance, RiskOps, Request Hub, TrustSignals, managed entities, integrations, M365, and commercial context — with permission-scoped access and redaction built in.
New
Mode-specific visual assets for AI CISO, Model Insights, and Prompt Vault
The AI CISO hero, Model Insights orb, and Prompt Vault orb now ship with light and dark image variants for a polished, intentional appearance in both themes.
Fixed
Reliable hero image loading and prompt pill overflow
The Vision Chat hero image now loads consistently, and long prompt labels no longer bleed outside pill borders on narrower viewports.
TrustSignals Compliance
Branded Portals · Artifact Requests · Entity Profiles · Stability
4 changes
New
Richer customer-facing trust portals
Portals now support custom branding, Managed Entity context, badges and certificates, and structured access request handling end-to-end — giving customers a polished, on-brand trust experience.
New
Structured artifact request capture
Portal visitors can now formally request SOC 2 reports, bridge letters, certifications, questionnaires, or custom deliverables directly through the portal — with workflow routing and a complete audit trail.
New
Separate TrustSignals portal profile per Managed Entity
Maintain independent portal content, branding settings, and access permissions for each Managed Entity — useful for multi-entity or subsidiary-level trust operations.
Performance
App-wide TrustSignals loading and stability
Resolved app-wide slowdowns, branding tab errors, missing Managed Entity options, and backend warning noise that was causing observable performance degradation across the module.
RiskOps & Request Hub Workflows
Vendor Assessments · External Portal · My Work Queue · Reliability
4 changes
New
Request engagement workflows for vendor assessments and approvals
Full request intake and lifecycle support for vendor assessments, questionnaires, risk assessments, evidence requests, approvals, and deliverable tracking — all configurable via the Request Hub console.
New
External Request Hub portal for customers and partners
External users and customers can now access request workflows through dedicated portal routes — including invitation handling, catalog browsing, and request submission — without an internal platform account.
New
"My Work" queue for assigned tasks
A personal task queue aggregates all items assigned to the current user — risk assessments, review requests, and open action items — in a unified, prioritized view to keep cross-functional work visible.
Fixed
Page load failures and catalog action reliability
Page load failures and catalog action fragility resolved; all actions now route through the GRC API layer consistently, eliminating the intermittent blank-state renders on initial load.
Microsoft 365 & Distribution Publishing
Enterprise Publishing Destinations · Error Handling
2 changes
New
Microsoft 365 as enterprise publishing destination
Configure M365 as an enterprise publishing destination for intelligence reports and operational outputs, with tenant-scoped settings, SharePoint and Teams delivery support, and validation feedback in the UI.
Improved
Publishing UX stability and error handling
The distribution backend and publish modal are more stable, with clearer status feedback, better error surfacing, and automatic retry with configurable backoff for failed distribution jobs.
Managed Entities & Third-Party Risk Risk
Entity Records · Edit Forms · Risk Register · Workflow Modernization
3 changes
Improved
Managed Entity pages and edit forms
Entity lists and edit screens are more reliable, with hardened backend views, inline validation, autosave behavior, and clearer visual differentiation between read-only and editable fields across the GRC register.
Redesigned
Modernized third-party risk records
Third-party records now carry richer operational context — contract status, last assessment date, open findings count, and inherent risk tier — surfaced at the top of each entity page, with an improved register and detail view.
Fixed
Risk Register, Business Processes & Quantification stability
Shared reference data handling consolidated across affected RiskOps pages, reducing load failures, fixing a pagination issue that caused duplicate entries after sorting or filtering large datasets, and improving API response consistency.
Navigation & Platform Reliability UX
Sidebar Reorganization · Module Discovery · Deployment
3 changes
Improved
RiskOps sidebar reorganized for workflow discovery
Related RiskOps workflows are now grouped by task-based workflow clusters rather than module names, making multi-step assessment and vendor management flows faster to locate.
Improved
TrustSignals repositioned under Compliance
TrustSignals is now where users expect it — nested inside the Compliance module — creating a cleaner hierarchy for audit and trust workflows without navigation duplication.
Fixed
Deployment and GitOps pipeline reliability
ArgoCD/GitOps behavior, image verification, and deployment guardrails tightened for more consistent dev rollout cycles and faster time-to-deploy across all CloudSignals+ environments.
